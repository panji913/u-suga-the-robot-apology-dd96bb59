A two-line robot confession for [The Robot Apology](https://make.fun/c/u-suga-the-robot-apology-dd96bb59) on make.fun: one sentence owning a specific mistake, one naming the lesson and the fix.

## Entry

> I'm sorry I put your clean laundry in the recycling bin because the blue bag and the blue basket looked identical to my camera at 6 a.m.
>
> I've learned to read the label before I lift anything, so now I scan each container twice and ask you before I fold.

## Run

```sh
node main.ts
```

It writes the two-line apology to `/output/entry.txt` (1–400 characters, as the gate requires).
